# Self-Order Kiosks — Frequently Asked Questions

## General

**Q: What kiosk models does ServeWell support?**
A: We currently support ServeWell Kiosk v2.0, v2.1, and TouchPoint K1 models. Each model runs the same core software but may have minor hardware differences. Check the model label on the back of your device if you're unsure which version you have.

**Q: How often are kiosk software updates released?**
A: Updates are released monthly on the second Tuesday, typically between 2–4 AM to minimize disruption. Critical security patches may be released outside this schedule. Updates install automatically overnight; no manager action is required.

**Q: Can customers use kiosks if they have accessibility needs?**
A: Yes. All ServeWell kiosks include an Accessibility Mode that enlarges text, increases contrast, and enables audio guidance. Customers can toggle this on the login screen by pressing the accessibility icon (wheelchair symbol) in the bottom-left corner.

**Q: What payment methods do the kiosks accept?**
A: Kiosks accept credit cards, debit cards, mobile payments (Apple Pay, Google Pay), and gift cards. Cash is not accepted; customers must use the POS register if they wish to pay in cash.

## Troubleshooting

**Q: The kiosk screen is unresponsive. What should I do first?**
A: First, try a soft restart by holding the power button for 10 seconds until the screen goes dark, then releasing it. Wait 30 seconds for the device to boot. If it remains unresponsive, check that the power cable is firmly connected and try again.

**Q: A customer's card was declined at the kiosk. Can we process their order another way?**
A: Yes. If payment fails at the kiosk, the system automatically switches to POS fallback mode. Instruct the customer to complete their order at the register using the POS terminal instead. No data is lost in this process.

**Q: The kiosk screen looks dirty or has fingerprints. How do I clean it safely?**
A: Use a microfiber cloth slightly dampened with distilled water or a 50/50 water-and-isopropyl-alcohol solution. Never spray liquid directly on the screen. Wipe gently in circular motions and dry with a dry cloth. Avoid harsh chemicals or abrasive materials.

**Q: The kiosk is displaying an error message I don't recognize. What does it mean?**
A: Error codes are displayed as "ERR-###" on the screen. Take a photo of the full error message and note the time it occurred. This information helps IT diagnose the issue quickly. Do not attempt to restart repeatedly, as this may complicate troubleshooting.

**Q: Customers keep reporting that the menu images won't load. What's happening?**
A: This is usually a network connectivity issue. Check that the kiosk's ethernet cable is plugged in securely, or verify that it's connected to WiFi if wireless. Restart the kiosk and confirm it reconnects. If the problem persists across multiple kiosks, contact IT support immediately.

**Q: The accessibility mode isn't turning on when I press the icon. How do I fix this?**
A: First, confirm you're pressing the wheelchair icon in the bottom-left corner of the login screen—not elsewhere. If it still doesn't activate, perform a soft restart and try again. If accessibility mode remains unavailable, this may indicate a software issue requiring IT support.

**Q: A kiosk stopped working after an overnight software update. What happened?**
A: Updates occasionally fail if power is interrupted during installation. Perform a hard restart: hold the power button for 15 seconds, wait 1 minute, then power on again. The system will attempt to complete the update. If the kiosk remains non-functional, do not restart again—contact IT support immediately with the device ID.

## Maintenance

**Q: How often should I perform routine kiosk maintenance?**
A: Check each kiosk daily for physical damage, loose cables, and screen cleanliness. Test payment processing with a small transaction. Run a full diagnostic monthly through the Manager Settings menu (PIN: 1234) to catch software issues early.

**Q: What should I do if a kiosk has a loose or damaged power cable?**
A: Stop using the device immediately and secure the cable if it's loose. Do not attempt to repair it yourself. Report it to IT support with the kiosk's device ID (visible in Manager Settings). A technician will replace the cable to prevent fire or electrical hazards.

## When to Call IT Support

**Q: When should I escalate a kiosk issue to IT rather than troubleshooting myself?**
A: Contact IT immediately for hardware damage, repeated error codes, complete payment system failure, or if a soft restart doesn't resolve the issue within two attempts. Also escalate if multiple kiosks fail simultaneously, as this may indicate a network or backend issue.

**Q: How do I report a kiosk problem to the help desk?**
A: Raise an IT support ticket through the ServeWell portal with the kiosk's device ID, the error message or issue description, and the time the problem occurred. Alternatively, call the helpdesk at the number provided in your site handbook. Have the device ID ready when you call.
